# 储物舱防脱锁止设计

2026-09-07。这是防退出机构与舱体接口的独立装配候选，尚未接入完整机身与燕尾导轨。未制造释放。

## 机构与装配顺序

Q06防脱销承接底座提供销尖盲孔与跨桥的四点安装面；Q07圆角跨桥采用顶板、中心承载套和两根立柱，给舱耳留出滑入空间；Q08圆帽螺旋定位销集成直径4销尖、直径8防脱肩、M6×1螺纹和手拧帽。三个自制件均为独立中文SLDPRT；紧固件采用M3×12、公称杆部简化模型，不能当作大工程师来源件。

先从跨桥下方插入销，旋入M6螺纹，再把跨桥安装到底座。防脱肩比上部孔大，因此不能在跨桥装好后从顶端强行插销。四个螺钉由上方装入，底部配置平垫圈与螺母；螺纹名义伸出2.6mm，机身设计必须保留下方工具空间。

装入舱体后顺时针旋至帽底止挡，销尖穿入原舱耳的直径4.2孔并进入底座盲孔。拆舱前卸除外载，逆时针旋出9圈，防脱肩升至内部止挡，销尖升至Z20；舱耳顶面Z19.2，名义剩余0.8mm间隙，然后沿负X方向滑出。销留在跨桥内，不成为游离零件。

## 明确的工程取舍

该候选优先解决销的丢失、装入方向和机械保持；9圈手动解锁速度较慢，尚未确定为最终交互方案。可在后续比较带机械保持的四分之一转销，但不能以仅靠重力落销替代保持结构。螺纹的振动防松、单手可操作性、帽面抓握和实际工具空间仍需试验。

跨桥初版采用实心桥顶，质量复查后改为3mm薄顶板、局部直径14承载套和分离立柱；几何改动后重建所有受影响装配、姿态与图纸。最终体积以JSON审核记录为准，不能沿用初版质量。

## 验证范围

装配采用实际基准面定位与可编辑距离配合，并直接检查当前配置的组件变换。检查销升0、3、6、9mm，以及完全解锁后舱退25、80、160mm七个离散姿态。每个正常姿态允许的唯一相交为M6公称杆与直径5攻丝底孔的简化交叠，理论体积约69.115mm³；分类同时限定组件对和体积，不能把整个销座的所有相交都忽略。

另建立两项故意越限配置：锁定时强制舱退1mm应检测到销与舱耳相交；销升9.2mm应检测到防脱肩进入止挡。这些配置用于确认阻挡确实存在，不作为正常工作位置，也不证明抗冲击强度。

原生零件图包含底座安装孔距、孔径、跨桥M6攻丝底孔及销肩直径/光轴长度的关联尺寸。装配图为结构审阅图，完整螺纹公差、剖面、零件序号和机身安装界面尚待制造审阅。

## 未完成的尺寸与强度工作

- 0.8mm解锁余隙须覆盖舱底、导轨、肩部及顶板高度误差；0.1/0.2mm单边名义间隙尚未做公差叠加。
- M6名义有效啮合8mm，需要扣除入口倒角和不完整牙；CAD没有实体螺纹及连续螺旋副。
- 100N轴向退出力只是结构初筛假设，得到直径4截面平均剪应力约7.96MPa、3mm舱耳名义挤压约8.33MPa；没有与实际材料疲劳、打印方向或强度许用值比较。
- 薄板、立柱、底座、螺钉、舱耳与整机安装位置仍须联合复核载荷；不能把几何无干涉称为承载验证。
- 连续扫掠、振动防松、污染磨损、寿命以及实物试装尚未完成。质量与全机外观也要在总装后再评估。

## 接入机身前必须处理的位置冲突

当前F11上板在X=65附近有70×64圆角减重窗，覆盖锁座拟安装位置X=71～95、Y=±27的大部分区域。因此不能把本锁座直接放在现有上板上称为安装完成。须设计跨窗支承或调整上板局部承载区，并保证螺母工具空间。还需统一导轨基面：本检查中舱底Z=16.2，短滑靴本身高度13.2，对应导轨基面Z=3；最终总装要计入这3mm安装高度，不能直接沿用另一总成的零点。
