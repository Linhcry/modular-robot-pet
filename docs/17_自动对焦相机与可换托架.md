# 自动对焦相机与可换托架

2026-09-08。本轮新增相机候选，不购买器件，不替换上一轮已审阅头部包。整机目标仍包括透明机械展示窗、实际驱动、控制板、线束和后续智能化。

## 选型与来源

原候选Pi5-IMX219-77的官方网页有25×24mm外形和4个安装孔，但本轮未取得可读的完整安装尺寸图和三维文件。保留该候选记录，不按估计孔距制造。

新增优先深入设计候选为Raspberry Pi Camera Module 3标准版，微雪中国商品SKU23943；是带PCB的完整相机，不是单独Sensor Assembly。支持自动对焦，官方标称11.9MP、75°对角视场、F1.8、4.74mm焦距。自动对焦用于靠近物体和与人交互场景，但运动模糊、低光和实际识别性能仍须测试。未核实即时库存和报价，未采购。

来源：[中国商品页](https://www.waveshare.net/shop/Raspberry-Pi-Camera-Module-3.htm)、[树莓派产品参数](https://www.raspberrypi.com/products/camera-module-3/)、[官方设计文件目录](https://pip.raspberrypi.com/categories/1207-design-files)。

已下载官方ZIP及标准版机械PDF；保留标准版STEP文件及SHA256。ZIP内同时有广角版，未混用。`V06_树莓派三代标准自动对焦相机官方参考.SLDPRT`保留标准版590个实体，已保存关闭。这是厂家参考转换，不是大工程师模型，也不能替代实际供货版本核验。

## 尺寸核对与版本差异

官方STEP坐标：PCB外形X0..23.862、Y0..25；四孔轴线X2/14.5、Y2/23，半径约1.1mm，对应孔距12.5×21、孔径2.2。原点不在镜头中心；光学封装中心约X14.4、Y12.5，镜头朝原坐标负Z方向。不能直接将PCB几何中心与D16镜头孔对齐。

官方PDF标注PCB厚1.12mm、总厚11.3mm；STEP大面积中间板体厚0.67056mm，铜层总体从Z−0.74422到+0.0127，整体外形Z−7.65..+2.595，总厚10.245mm。PCB单体不是全叠层，且当前全叠层仍与PDF不同。此差异未解决，安装高度与夹紧尺寸尚不能制造放行。来源记录见`vendor/electronics_sources/CameraModule3_官方来源.json`；提取报告见`CameraModule3_STEP安装接口预读.json`、`CameraModule3_光学封装预读.json`。

## 头部坐标和结构

候选安装变换为：头部X=相机Y−12.5，头部Y=相机X+15.6，头部Z=53.85−相机Z。该变换是正交旋转加平移，不是镜像；镜头封装朝头部前方，中心X0、Y30。按当前STEP，最前方Z61.5，相比齐平面框前面Z62.2后缩0.7mm。四安装孔位于头部X±10.5、Y17.6/30.1。

H12保留H06原有屏幕孔、四处承架紧固孔和扎带槽，扩大相机维修避空为28×29.5、中心Y27.75；增加X±20、Y25的两个D3.4托架连接孔。H06原文件保留。

H13为独立PA12绝缘开框托架。局部原点安装于头部(0,30,51.2)；主框27.8×18、内窗口16×12，主板厚1.2并抬高0.5；双侧安装耳底面贴承架、总宽45，外缘C0.15，平面转角R1.5/R2。四个D3.8支承柱只按当前参考模型的安装焊盘附近支承；铜层压紧、器件禁压区和爬电/绝缘不因使用PA12自动通过。

四个相机通孔D2.2，孔距21×12.5；柱顶局部Z2.6373，对齐当前STEP板背头部Z53.8373。这是来源模型的定位值，不是冻结的制造精度。后插座留在开框上方，避免用实心托板挡住排线插座和拔插方向。

## 紧固与光路后续

规划相机4组M2贯穿螺钉与六角螺母；托架2组M3连接到承架。标准件应对应GB/T尺寸族和中国可购型号，螺钉长度需依据最终PCB厚度、实际头部几何和板背支承核验。当前未完成这些紧固件的原生装配，不把基准配合视为已经完成物理固定。

D16孔的光学检查应采用75°对角视场和新的入瞳预算。镜头机械前表面不是入瞳；尚不能仅凭“镜头装得进去”宣称全视场无暗角。仍需确定真实入瞳、检查光路与面框/托架遮挡，并实拍验证。

后续顺序：原生空间与孔轴检查 → 修正干涉 → 完整紧固及工具通路 → H12/H13独立工程图与装配图 → FPC应力释放和颈部弯曲路径 → 控制板/散热布局。头壳STEP导出问题沿用16号记录继续排查。

## 本轮已完成的验证

完整相机首次装入后，H13与两颗板背器件发生约1.06及1.05mm³交叠。以相机590个原生实体逐件筛选，208个包围盒接近托架的实体进入求交，定位到厂家实体202与493。H13增加两处4.2×4.2、R0.6圆角贯通避空，位置分别为局部(8.7,−4.6)、(−8.7,−6)，未削去四个支承柱。修正前报告及零件保留在validation/wip。

修正后重开装配检查通过：27组件、58配合、无配合错误、无名义刚性干涉。相机590个实体均保留，选中PCB实体Check2原始返回0，四孔轴到托架设计轴最大平面偏差约0.00000123mm（CAD数值一致性，不是制造精度）。报告`validation/自动对焦相机头部空间检查.json`。

H12/H13均为独立单实体SLDPRT、无特征重建错误、Check2原始返回0。H12体积8939.8025mm³；修正后H13为539.5194mm³，按PA12密度1010kg/m³设计假设约0.545g。两个STEP均通过独立闭合实体检查，体积与原生差小于0.000001mm³；不将该结论延伸到有问题的H10头壳STEP。

H12/H13独立SLDDRW及自动对焦头部装配SLDDRW已生成，对应三页PDF已渲染查看。当前是空间与接口候选；相机M2和托架M3完整紧固件尚未加入，所以27组件空间总成不是物理紧固完备的头部总成。

新的D16孔光学预算：按75°对角视场、F1.8和4.74mm焦距估计入瞳半径1.3167mm，预留0.5mm横向偏心时，允许入瞳距前面框最大后缩8.0583mm，即入瞳Z不低于54.1417。真实入瞳位置仍未确认；镜头机械端面Z61.5不能直接代入该条件。计算见`validation/CameraModule3_D16光学条件预算.json`。
