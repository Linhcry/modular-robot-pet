# 机械结构参考阅读与设计取舍

更新：2026-09-07。当前已完成50项首轮结构阅读与迁移判断；不少于50项的首轮比较目标已达到。52项候选清单、下载成功数和CAD零件数量均不能代替已阅读数。

本表是原作者论文、手册或项目文字的首轮比较，未声称完成全部原生CAD拆解、强度复算或实物试验。对本宠物的应用是工程推断。一个机型系列仅计一项，未以左右件、版本或驱动变体重复计数。

## 对现有方案的直接影响

- 驱动允许比较无刷电机与智能舵机；持续负荷、速度、电压、反馈、质量及壳内散热共同决定，堵转扭矩不能直接作为工作扭矩。
- 腿部近端驱动必须计入髋膝耦合，已有独立计算见[传动耦合报告](09_膝驱动近端化与传动耦合.md)。
- 不增加重型灵巧手；先保留满足钥匙、遥控器、纸巾拿取的轻型夹爪研究，储物舱不替代机械臂。
- 护壳用曲面，承载接口保留可测量的平面/圆柱基准；壳体不可遮蔽散热、线束和维修路径。
- 快拆连接需要独立机械保持，机身贯穿螺钉需要压缩隔套形成夹紧路径。

## 已阅读条目

### R01 Stanford Doggo

来源：[原始资料](https://github.com/Nate711/StanfordDoggoProject)；定位：README / Mechanical Design。

结构观察：同轴双驱动五杆腿，16/48齿同步带，双轴承支承；作者记录预紧与摩擦的取舍。

用于本机：保留近端驱动与独立承载轴承候选，计算耦合和带张力。

边界：二维腿不能直接替代三轴腿；未审阅全部CAD。

### R02 Pupper V3

来源：[原始资料](https://pupper-v3-documentation.readthedocs.io/en/latest/learn_more/tech_specs.html)；定位：Technical Specifications / Actuators。

结构观察：V3为12自由度、3kg；GIM4305为10:1行星传动，约3.5Nm峰值，空气冷却条件下约1Nm连续。

用于本机：小型无刷关节进入比较表，头部视听与轻型耳驱动分开分配质量。

边界：连续值有冷却条件；不能用峰值覆盖站立热负荷，未冻结本机型号。

### R03 Solo / ODRI早期八自由度

来源：[原始资料](https://arxiv.org/abs/1910.00093)；定位：论文第2页 Actuator Concept；第8页版本说明。

结构观察：早期Solo为8自由度、2.2kg；150g驱动模块含9:1两级同步带，电流12A对应2.7Nm。

用于本机：借鉴电机、带轮和承载连杆集成，以及单腿台架和足接触检测。

边界：论文该重量属于早期八自由度有线平台，不能标成无线Solo12；峰值非连续。

### R04 Dingo

来源：[原始资料](https://github.com/Yerbert/DingoCAD)；定位：README / Some build notes。

结构观察：电机附近零件要求ABS，作者报告PLA受热软化；膝传动轮毂分体嵌轴承，使用热熔嵌件。

用于本机：打印护壳与电机承载/散热路径分开；考虑轴承装入顺序和嵌件。

边界：35kg舵机是项目用语，不能当成35kg载荷或持续扭矩；仓库有SW/STEP入口，未全几何审阅。

### R05 Mini Pupper

来源：[原始资料](https://mangdangroboticsclub.github.io/MiniPupperDocs/en/guide/Assembly/MiniPupper.html)；定位：官方装配指南 Step 3.1 / 单腿与髋装配。

结构观察：连杆长度以配对杆校准，转轴配轴承、隔离夹紧与转动；同侧前后腿共用，左右镜像。

用于本机：独立列出轴承装入方向、连杆中心距和锁紧后转动检查，避免螺钉夹死活动件。

边界：教程给出装配经验而非配合公差；M2级小平台不能直接承受本机负荷，未审阅全部CAD。

### R06 Petoi Bittle

来源：[原始资料](https://guide.petoi.com/product/bittle-x-v2/quick-start-guide/assembling)；定位：Bittle X V2 Assembling / Upper leg、Lower leg、Battery。

结构观察：上腿带弹簧，左右腿镜像且前后共用；下腿长线从肩舵机旁开口穿入；电池通过带锁扣滑槽连接底部。

用于本机：软垫、弹簧、刚性限位分开设计；借鉴模块化电池和接头应变释放，活动线束随姿态检查。

边界：此处为Bittle X V2装配版本，不能混用早期9轴配置；弹簧装配教程不能证明本机跌落能力。

### R07 HyperDog

来源：[原始资料](https://arxiv.org/abs/2209.09171)；定位：论文第2–3页 / Mechanical Design of the Leg。

结构观察：150mm上下腿，打印件与碳纤维组合；三个伺服均靠近腿根；下腿弹簧缓冲与TPU足垫。

用于本机：近端化减少摆腿惯量，足端软垫与限位分工，保留长腿跨阶空间。

边界：文中单腿0.95kg，对5kg带臂宠物仍很重；其膝运动范围不能直接满足本机148度轨迹。

### R08 MIT Mini Cheetah

来源：[原始资料](https://news.mit.edu/2019/mit-mini-cheetah-first-four-legged-robot-to-backflip-0304)；定位：MIT原始报道 / Dynamic stuff。

结构观察：每腿三只可更换同型驱动；模块集成无刷电机、6:1减速、控制与位置检测。

用于本机：减少驱动接口种类并使承载模块可更换，优先短反力路径。

边界：整机为约9kg级平台；其跳跃能力不能通过尺寸缩放移植，尚未审阅全制造图。

### R09 MEVIUS2

来源：[原始资料](https://haraduka.github.io/mevius2-hardware/assets/paper.pdf)；定位：论文摘要、图2 / Design overview。

结构观察：用钣金焊接和机加工合并承载零件；排除镜像后16种金属件，并把传感器防护作为独立部件。

用于本机：比较折弯承载件与多片螺接框架的件数、质量和装配误差；护罩保留圆润外形。

边界：大型平台的焊接厚度与耐冲击结论不能外推到小宠物；焊接变形与返修代价需另算。

### R10 Unitree Go2

来源：[原始资料](https://www.unitree.com/go2/)；定位：官网参数表 / Knee Joint Parameters。

结构观察：三轴腿；铝合金与工程塑料组合，列出关节范围、内部电路和散热结构。

用于本机：最终轴线范围要与外罩、走线和散热一并建模，不能只校验电机空载角度。

边界：约15kg含电池；45Nm为特定最大关节峰值，不是全关节连续值，配置有差异。

### R12 Boston Dynamics Spot

来源：[原始资料](https://dev.bostondynamics.com/docs/concepts/about_spot)；定位：SDK / Legged Locomotion与关节范围。

结构观察：每髋两轴、每膝一轴；髋俯仰范围带零位偏置，膝从近伸直到深屈曲有明确限制。

用于本机：建立每轴机械零点、符号及软件限位表，配置与坐标转换共同审核。

边界：该文档含Spot Gamma历史参数，不能与新版重量混用；未取得本机完整爬阶碰撞证明。

### R13 Ascento

来源：[原始资料](https://arxiv.org/abs/2005.11435)；定位：论文第2页 / Mechanical Design。

结构观察：两轮腿，髋部电机驱动近似直线的连杆伸缩；并联弹性辅助跳跃，杆长经优化。

用于本机：保留轮腿为可更换模块方向；研究重心附近推力线与弹簧回收。

边界：轮腿平衡与四足动作不同；近直线连杆并非严格直线，不能忽略侧移。

### R14 Wheelbot

来源：[原始资料](https://arxiv.org/abs/2207.06988)；定位：论文第3–4页 / Mechanical design。

结构观察：两个相同轮总成；铜环配重形成反作用惯量，O形圈外胎，电池按轴对称布置。

用于本机：观察对称布置和可拆轮胎；评估翻正前先算惯量及所需角动量。

边界：配重增惯量会增加整机质量；不能为翻正盲目加飞轮，也未移植其控制。

### R15 Cassie

来源：[原始资料](https://raw.githubusercontent.com/wiki/agilityrobotics/cassie-doc/Kinematic-Model.md)；定位：原厂 Kinematic Model / General Information 与关节顺序。

结构观察：腿含膝弹簧、跟部弹簧和连杆；足趾与趾输出曲柄保持平行，弹簧未挠曲时大腿与跗段相对平行差13度。

用于本机：把被动弹性坐标、约束杆和主动关节分别列入动力学；镜像规则需在全局坐标复核。

边界：原模型将连杆和趾曲柄视为无质量，是计算假设而非实体属性；原仓库已归档，不作为当前可采购整机。

### R16 ToddlerBot

来源：[原始资料](https://arxiv.org/html/2502.00893v2)；定位：论文 III-B 与 VIII-D Transmission Mechanisms、VIII-E。

结构观察：直齿轮移开轴线并把横向载荷转移到独立轴承；腰用双电机锥齿轮耦合；膝和颈俯仰用平行连杆将驱动上移。

用于本机：优先研究独立承载副轴，近端化必须重新计算耦合与惯量；头颈可借鉴紧凑平行连杆。

边界：论文指出平行连杆范围通常小于160度；不能默认覆盖本机全动作。电机表是堵转值，不能用于连续热选型。

### R17 Berkeley Humanoid Lite

来源：[原始资料](https://arxiv.org/html/2504.17249v1)；定位：论文 III-C2 / IV-B Transmission Stiffness / IV-C Durability。

结构观察：两种尺寸打印摆线减速关节；贯穿螺钉及嵌入黄铜六角支柱抑制层间失效；PLA齿轮经过特定60小时摆锤寿命试验。

用于本机：比较多齿接触减速与可更换磨损件，打印件的层间夹紧路径单独设计；寿命试验按本机负载重做。

边界：16kg、0.8m平台；60小时工况为0.5kg、0.5m摆锤和0.5Hz，不等于宠物寿命，也不证明轻量化达标。

### R19 Open Duck Mini v2

来源：[原始资料](https://raw.githubusercontent.com/apirrone/Open_Duck_Mini/v2/docs/assembly_guide.md)；定位：Open Duck Mini v2 assembly guide / trunk、feet。

结构观察：躯干先装轴承和M3嵌件，再合上下壳；足部将TPU接触底和PLA刚性底螺接，可压入触地开关，左右足共用。

用于本机：足垫设计为可更换部件，触地开关安装高度需和压缩量共同确定；保持轴承先装的维修顺序。

边界：文档紧固件数量仍有TODO；触地开关不能代替连续足底力传感，尚未核读全部图片/CAD。

### R20 ROBOTIS OP3

来源：[原始资料](https://emanual.robotis.com/docs/en/platform/op3/introduction/)；定位：官方手册 / OP3 Specifications。

结构观察：20自由度，XM430-W350-R执行器，OpenCR下位控制；重量约3.5kg且不含外皮。

用于本机：串行智能舵机作为人形与轻载关节候选，保持关节反馈和上下位控制分层。

边界：手册有不同硬件代次，电池与计算机配置不混用；无外皮重量不等于宠物全重。

### R21 Poppy Humanoid

来源：[原始资料](https://flowers.inria.fr/PoppyHumanoids2014.pdf)；定位：论文第3–4页 / Platform overview。

结构观察：25个驱动，躯干五关节，弯曲大腿与可更换打印形态；通过更换足形实验比较步态。

用于本机：尾部和躯干表达采用可替换机构；先测试足形，再扩大动态动作。

边界：原文图表与正文高度版本有差别；不引用单一高度做本机缩放，当前不增加五轴躯干。

### R22 igus Humanoid Open Platform

来源：[原始资料](https://arxiv.org/abs/1809.11110)；定位：论文第2页规格表和结构说明。

结构观察：PA12打印结构；每腿6轴、每臂3轴，20个MX系列驱动，92cm/6.6kg。

用于本机：人形转换模块单独定义髋踝承载和足底接触，使用便于单件更换的结构。

边界：打印外形不代表低重量；大型人形舵机数量和价格不直接落入本机预算。

### R23 Reachy 2

来源：[原始资料](https://docs.pollen-robotics.com/hardware-guide/specifications/general/)；定位：General specifications / Architecture。

结构观察：七轴臂由两组Orbita 2D和一组Orbita 3D并联关节组成；颈部也用3D机构，内部走线。

用于本机：保留复合关节用于头部表达的研究接口；左右共用模块减少零件种类。

边界：不能按七轴串联臂公式直接控制并联关节；尺寸、质量与成本仍需独立核对。

### R24 Unitree G1

来源：[原始资料](https://www.unitree.com/g1/)；定位：官网 / Joint output bearing、Mechanical Dimensions。

结构观察：6轴腿，交叉滚子输出支承，双编码器与中空走线；基本型和EDU的手腕/腰配置不同。

用于本机：负载通过输出支承进入结构；驱动、轴承、线束包络同时设计。

边界：23与23–43自由度属于不同配置；35kg级平台不能直接按比例缩成5kg。

### R25 SO-101

来源：[原始资料](https://github.com/TheRobotStudio/SO-ARM100)；定位：README / Sourcing parts与SO101版本说明。

结构观察：智能串行舵机臂；SO101改进布线和装配，主从臂减速比和供电有区别。

用于本机：借鉴按轴校准、线束余量与低成本示教；舵机规格按具体电压和齿比建表。

边界：SO100/101作为一个系列计数；文中STS3215堵转扭矩不等于本机持续肩扭矩。

### R26 ALOHA

来源：[原始资料](https://arxiv.org/html/2304.13705v1)；定位：ALOHA原论文 III / 图2与handle and scissor段。

结构观察：主从臂采用关节映射；主手增加手柄剪式机构连续控制夹爪，并以橡皮筋辅助抵消重力；从手腕配近距离相机。

用于本机：宠物夹爪保留连续开口控制和近距离视觉；如做示教器，单独设计助力，不把人手操作力施给脆弱输出轴。

边界：平衡橡皮筋装在主手侧，不是从臂增载证明；论文20k美元双臂系统不进入本机采购预算。

### R27 OpenMANIPULATOR-X

来源：[原始资料](https://emanual.robotis.com/docs/en/platform/openmanipulator_x/specification/)；定位：官方 / Specifications与Inertia。

结构观察：四臂轴加夹爪，标称500g负载、380mm臂展；提供分连杆质心与惯量表。

用于本机：小宠物臂先按拿取任务选择必要轴数，并用每段质量重算肩肘，不只看末端负载。

边界：规格重量0.70kg与惯量总质量711.37g应记录来源口径；末端工具质量不能漏计。

### R28 PAROL6

来源：[原始资料](https://source-robotics.github.io/PAROL-docs/page2_2/)；定位：官方 Robot Specifications / Gear ratios、Operating temperatures。

结构观察：六轴步进臂混用同步带与行星减速；J3为20倍行星再乘38/42带比；PETG承载件需要限制持续发热。

用于本机：各轴建立完整传动比表，减速、微步分辨率和真实定位误差分别记录；关节热源远离曲面薄壳。

边界：基座附近1kg、全工作区0.5kg有区别；开环微步角不等于实际精度，整臂5.5kg不适合直接装上宠物。

### R29 Thor

来源：[原始资料](https://github.com/AngelLM/Thor)；定位：README / Technical Specifications。

结构观察：六轴串联，步进电机、打印齿轮与GT2同步带；提供FreeCAD源文件和STEP。

用于本机：学习电机后移和混合传动，把可打印护罩与承载支承分开。

边界：750g最大承载包含末端执行器；步进开环方案不能直接用于受碰撞的宠物腿。

### R30 BCN3D Moveo

来源：[原始资料](https://raw.githubusercontent.com/BCN3D/BCN3D-Moveo/master/USER%20MANUAL/User%20Manual%20BCN3D%20Moveo.pdf)；定位：原厂装配手册第6、14、16页（已查看渲染）。

结构观察：底座由8组小轴承和隔套支承；肩模块两侧电机经同步带作用于大轮，穿轴由两侧轴承支承，外侧再装端盖。

用于本机：借鉴驱动与承载分离、贯穿轴和可拆端盖；总成图补充装入顺序，确保轴承和隔套可实际装到位。

边界：手册若干西英螺钉长度翻译不一致；仅审阅关键模块页，不复制整臂尺寸或宣称其标准件已完成国标替代。

### R31 Annin AR4

来源：[原始资料](https://anninrobotics.com/docs/what-are-the-dimensions-and-key-specifications-of-the-ar4-robot/)；定位：制造商 / Key specifications及MK3指引。

结构观察：桌面机械臂使用金属结构，67cm臂展、1.9kg负载，铝结构整机12.25kg。

用于本机：用完整臂质量与载荷的比例约束宠物机械臂，避免复制过大的工业形态。

边界：这里只核读MK3规格指引，未审阅整个装配手册；不将MK5外形混入。

### R32 MeArm

来源：[原始资料](https://github.com/MeArm/MeArm)；定位：README / Version History。
