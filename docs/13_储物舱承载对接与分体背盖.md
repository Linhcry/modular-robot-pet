# 储物舱承载对接与分体背盖

2026-09-08。本轮是储物舱、导轨、锁止机构与外壳的机械对接，未制造释放。

## 承载板与导轨基准

新增F13锁座连体支承上板，保留220×190×2、外圆角R14与原侧梁安装孔。把右侧减重窗由70×64缩为35×64，保留X=75/91、Y=±21四个锁座安装孔下方的完整材料。它是独立新零件，不覆盖旧F11。

两条燕尾导轨各由三块Q09圆角等高垫块支承。垫块16×14×3、R2、中心D3.4，位于X=-50/0/50、Y=±45。上板底面为Z=0，顶面Z=2，导轨底面Z=5，舱底Z=18.2，锁座与跨桥整体抬高2mm。锁销仍提升9mm解锁。不要混用早期独立锁座装配的坐标。

导轨沉孔D6.2容纳M3螺钉头D5.5；不放OD7的普通上垫圈。六个M3×16螺钉从沉孔底面Z=10向下穿入，板下放垫圈与螺母，名义伸出3.1mm。四个跨桥M3×16螺钉依次夹紧上垫圈、桥脚、底座、F13、下垫圈和螺母，名义伸出4.6mm。均为已有公称简化标准件，尚未冻结大工程师来源商品。

`储物舱_导轨锁止与承载板.SLDASM`包含完整49件储物舱子装配；顶层47个实例、含子件总计96个实例（包含子装配节点），对应95个叶零件实例。顶层138个真实基准面配合。六个离散姿态包括装入、开盖90度、解锁以及退出25/80/160mm；无配合错误，九处相交均为明确组件对的螺纹简化交叠，未发现额外实体干涉。

另外核对40处实际圆柱面/螺钉轴，确认十组贯穿连接的孔轴一致。该结果不是接触预紧力或强度验证。

## 外壳冲突与分件方案

把真实B01/B02护壳加入后，旧B02在锁定姿态与Q07跨桥、Q08定位销相交；滑出25mm开始与舱体相交，在80/160mm还碰内托盘。此失败检查保留在`储物舱对机身护壳空间检查.json`，不能把不带外壳的六姿态检查代替整机维护检查。

新增B04锁座避空曲面主背盖和B05可拆曲面后背盖，均从B02的原生放样、抽壳特征独立复制。接缝在X=-77附近，两件之间留0.6mm名义间隙。B04增加26×64、R6的锁座连通避空口；B05保留后部原有拱面与下壳止口配合。

两块Q10连接压板跨接前后盖，尺寸44×14×2、R3、孔距26。四个支承座顶面均为背盖局部Z=39，底面Z=32，孔位X=-90/-64、Y=±78。四组M3×16、上下垫圈与螺母夹紧，名义螺钉伸出3.6mm。

日常取放物品只开储物舱盖。拆整个舱体前，清空载荷、托住模块，先卸两块压板及相应紧固件，抬起后盖解除下壳止口并移出维护范围，随后解锁销并沿负X滑出舱体。装配配置中的后盖抬高120mm表示已移出路径，并不是后盖自带升降机构。拆出的螺钉、垫圈、螺母需收纳；当前不是防掉落紧固方案。

`分体曲面背盖与储物舱_维护候选.SLDASM`顶层22个实例、总计118个实例（包含两个子装配节点），即116个叶零件实例。顶层64个配合特征含分别用于上下维护位置的两个互斥距离配合，避免距离翻转影响其他配置。十一种离散姿态均在全部配置写入后重新切换检查，保存后再次打开确认真实舱体、舱盖与后盖位置；无配合错误、无额外实体干涉。另核对12处背盖、压板和螺钉的实际孔轴。它仍不含全套机身侧梁、关节与电子走线。

## 质量、刚度与未完成项

按铝密度2700kg/m³假设，F13约138.46g，比F11约增11.90g；六块Q09合计约10.26g。按PA12密度1010kg/m³假设，B04约90.47g、B05约54.24g，两者尚未计压板和紧固件。不能据此更新未选电机的全机质量；上一版9.662kg整机估计仍不满足4～5kg目标。

导轨50mm支承中心距做了单位载荷名义梁初算，见`导轨跨距名义梁初算.json`。模型只保留底部2mm厚净截面、忽略上部燕尾刚度，用E=69000MPa假设；25N单轨跨中载荷得到约28.24MPa名义应力、0.0853mm挠度。25N是筛选载荷，未证明它覆盖整机跳跃或偏载。孔边应力集中、承载板柔度、预紧力和轨靴接触都未计入。

F13外侧减重窗会使载荷绕经端部和周边板带传至侧梁，仍须完成整板弯扭与螺钉连接校核。背盖螺母的防转/防掉落、批头与手指空间、外壳最终固定、接缝工艺公差、密封和连续扫掠尚未完成。几何检查不能替代样件试装。

透明观察窗另见`12_透明观察窗与维护空间规划.md`。按两块主窗和一块可选窗布局，不在背盖上密集开小孔；实际窗口位置随最终驱动与走线布置冻结。
