# 模块化机械宠物 — SolidWorks 详细建模规划

版本：P0.1；日期：2026-09-05。阶段：参数化结构样机设计，不是已完成实物验证的生产图。

## 1. 任务与不可丢失的要求

- 一个可迁移的智能核心，搭配人工重组的关节、连杆和功能模块；首先验证移动宠物、桌面助手。
- 主体为 300–350 mm 级，肢体展开尺寸可以超过主体；收纳时折叠。完整移动构型质量目标 4–5 kg（不含货物）。
- 本体基本动作包括多方向移动、身体姿态变化、头尾表达、伸爪、翻正、可控小跳和楼梯。
- 货物总质量不超过 300 g；机器人自主拾取钥匙、小遥控器、纸巾软包等，将其装入储物舱后运输，到达后取出。拾取范围为地面至 200 mm 高的低台。
- 满载楼梯目标为 150–180 mm 级高、踏面深度不少于 250 mm 的干燥防滑室内闭合直梯。单级越障不等同于连续楼梯。
- 预算 30000 元，保留不少于 6000 元试验与返工。当前不采购；标准件采用中国可获得的适用 GB/GB/T 公制规格。
- 必须交付独立 SLDPRT、SLDASM 子装配/总装、SLDDRW 零件工程图和装配工程图。提供 STEP、预览与审核记录。

## 2. 本轮输出边界

本轮建立可继续编辑的机械结构设计基线：真实实体、特征树、安装孔、承载连接、运动轴、配合、倒角/圆角和工程图。电机、电池、计算板及相机在未确定采购型号前采用明确标注的包络/接口假设件；不冒充厂家精确模型。

零件模型可通过特征树编辑；集中参数和可重复生成脚本用于追踪修改。工程图记录关键尺寸、孔位、材料假设和未释放状态。所有不能通过当前软件直接验证的指标，列入待验证清单，不以“已建模”代替“能实现动作”。

## 3. 建模与装配基准

统一坐标：X 为机器人前方，Y 为机器人左方，Z 为上方；单位 mm、kg、N、N·m，SW API 中长度转换为 m。总装基准原点位于主框架中心。零件优先在默认基准面上建草图，通过实体/参考基准配合安装，避免依赖易变的边编号。

- 基准 A：主承载框架安装面。
- 基准 B：纵向对称中心面。
- 基准 C：前部模块定位面。
- 每个关节具有轴线、安装面和角度零位。运动部件保留单个预期转动自由度，展示姿态使用可抑制的角度配合/配置锁定。
- 刚性接口以定位特征承担重复定位，以紧固件预紧保持连接；不能仅靠螺钉杆与间隙孔定位。
- 两轴承/双耳支撑优先于单边悬臂；电机输出轴与外部结构承载轴的职责分别记录。

## 4. 产品分解与零件建模

### A. 中央承载与模块接口

主框架采用上/下承载板、侧向连接梁、局部加强筋和可拆盖板形成封闭或半封闭截面。四角设置腿模块安装面；智能核心、电池与储物舱通过独立安装板固定。

零件：下承载板、上连接板、左右侧梁、前/后模块适配板、电池托架、电子托板、服务盖板、定位柱/衬套。先检查腿反力和机械臂反力到主梁的路径，再安排减重窗口。

### B. 可重组三轴腿

初始运动拓扑为髋外展、髋俯仰、膝俯仰，四条腿共用同一零件族；左右安装通过变换或左右适配件实现，不能仅把实体镜像后假定轴向一致。

参数比较从大腿/小腿 140/140、160/150、170/160 mm 三组开始。最终装配实例采用经包络与干涉检查后的一个基线，其他参数留在设计表中。

零件：髋安装座、关节壳体/电机假设件、输出法兰、双耳支架、大腿杆、小腿杆、足端连接座、弹性足垫、铰轴、轴承/衬套和轴向限位件。腿部电缆具有弯曲空间及固定点，不穿过闭合转动的实体区域。

### C. 身体/头尾活动模块

身体柔性方案需检查储物舱是否跨越活动接口。第一版先完成独立躯干活动模块的轴系与行程包络，只有连接、重量与碰撞校核成立时才加入总装。

头部使用可更换面罩、相机窗口、麦克风开孔、转动支架与承载基座。尾部采用轻量连杆，不作为承载翻正工具，除非另行完成受力校核。

### D. 自动装卸机械臂

机械臂按“地面/200 mm 低台/舱内”三个工作区域建立姿态点集合，检查位置与夹爪朝向。肩部安装位置与舱口同时确定；收拢后夹爪和连杆不能进入腿部运动包络。

零件：臂基座、肩支架、上臂、肘支架、前臂、腕部组件、夹爪底座、自适应手指、柔性指垫、薄物托取接口。关节数量以这些任务姿态是否可达来论证，不能靠增加无用途的关节堆叠自由度。

薄物、软物不能用相同摩擦系数和刚体抓取假设证明。第一版几何会保留可换指尖与托取接口，抓持可靠性留给后续夹爪台架验证。

### E. 储物舱

采用低矮硬壳舱、圆滑内角、可拆浅托盘、可换分隔件及舱盖。舱内需要保留夹爪再次进入的空间，不能只按物品最大外形设计舱口。

零件：舱底/壳体、舱盖、铰链件、铰轴、盖驱动安装座、内托盘、隔挡/柔性内衬假设件。舱盖闭合使用锁止/保持机制，传感器安装空间单列。

### F. 标准连接件

主要连接必须包含螺钉头和完整杆部，必要时加入螺母、垫圈、定位销和轴承。螺纹可简化为配合直径并用工程图注释标识，不能把攻丝底孔与螺钉实体交叠全部当作错误，也不能把真实结构碰撞归入螺纹接触。

孔与紧固件记录：连接编号、被连接零件、孔径、沉孔/沉头、螺纹、啮合长度、螺钉长度、装拆方向。规格与准确标准版本在制造释放前再次核查。

## 5. 特征、倒角与工程图规则

- 特征命名体现用途：承载外形、安装孔、轴孔、减重窗、加强筋、装配避空、倒角、圆角；禁止整件仅剩导入体而没有设计说明。
- 先形成有效实体，再做孔槽，再做加强与避空，最后做倒角/圆角；失败的特征必须修复或在记录中明确保留原因。
- 非功能外缘先以 C0.3–C0.5 作为样机倒角假设；圆滑外壳/接触边采用更大圆角。轴承座、定位面、螺纹入口分别处理，不对所有边统一倒角。
- 每个自制零件至少有三视图或适当剖视/局部视图及等轴测视图；标注外形、厚度、轴孔、安装孔位置、材料与关键配合说明。
- 子装配图标明运动轴与装配方向；总装图包含构型名称、外包络、主要模块和物料明细。
- 图纸首版标记“结构样机设计/未制造释放”。尚未选型的厂家孔位不能作为生产孔位直接下发。

## 6. 装配配合与配置

- 主框架作为固定基准；其他构件逐一列出是固定安装、刚性配合还是转动配合。
- 旋转副采用同心＋轴向定位，另用平行/角度配合确定零位；需要运动时抑制角度锁定，不能同时加入互相冲突的定位约束。
- 螺栓连接要核对同轴与实际夹紧层次。使用坐标变换初始定位不能替代配合审核。
- 计划配置：标准站立、低姿、运输收拢、舱盖开启、装卸示意；左右腿与关节方向在每个配置中保持一致。
- 自碰撞至少检查标准站姿、收拢姿态和装卸姿态；腿/臂运动扫掠属于进一步检查，不能用单姿态零干涉代替全行程证明。

## 7. 审核与验收证据

1. 零件：逐个打开，确认实体数、重建错误、特征、包络、材料/密度假设与保存结果。
2. 装配：核对实例数量、缺失引用、固定状态、配合状态、预期剩余自由度；不得以全固定装配冒充可动机构。
3. 干涉：使用 SW 实体干涉检查；输出部件对与交叠体积。明确区分螺纹简化、过盈假设和非预期碰撞。
4. 连接：孔轴同心、支架间隙、紧固件夹紧范围、轴向保持、工具可达性。
5. 图纸：逐张查看布局、视图、尺寸及注释，确认没有裁切、重叠和空白图。
6. 输出：SLDPRT、SLDASM、SLDDRW、STEP、PDF/PNG预览、BOM、参数文件、生成脚本、检查记录与开放问题清单。

质量和承载：质量目标必须使用实际零件材料、假设件质量和线束/紧固件余量；在驱动、电池型号未选定前仅能给出估算。静态重力、动态关节力矩、落地冲击、温升、脚地摩擦和机械臂抓持需要后续计算/台架/实物闭环，不在本轮伪造验证结果。

## 8. 本轮实施顺序

先进行 GitHub skill 审阅与 SW 连接检查；再验证一个带孔、倒角的零件和一个真实配合子装配；随后生成承载结构、腿模块、头部、储物舱、机械臂并总装；再生成独立零件图与装配图；最后修复重建/配合/干涉问题、核对工程图、导出与打包。

后续每次改变结构参数，都同步更新受影响零件、子装配、总装、工程图与审核记录。当前没有采购行为。


## 9. 当前追加约束与曲面策略（2026-09-05）

- 全部零件文件、装配实例和工程图标题用中文；编号保留。
- 零件逐一重建、保存、关闭；全部自制零件和采购件接口准备好后再总装。
- 安装面、定位面和板件保留平面。头壳采用四椭圆截面放样与3mm抽壳；舱盖采用圆角矩形变截面放样与2.5mm抽壳；连杆使用圆弧端部、收腰和减重孔。
- 储物舱增加燕尾滑轨、滑靴和防退出销，区别于普通螺钉堆叠的模块更换方式；实物间隙按材料、工艺和磨损另行校核。
- 电机与舵机必须对应可采购型号，不能把早期J01/J02概念包络当作最终厂家模型。优先使用厂家尺寸图/STEP；未知细节保留空间并注明。
- 用户正在安装大工程师；安装完成后核对并调用其中的采购件、标准件，不能把自画的简化标准件冒充该库原件。
- 装配保留实际运动轴、轴向定位与合理的剩余自由度；刚性锁定仅用于静止安装，不替代转动副。
